# INDUSHI - Indonesian Fusion Sushi

> 100% Cooked, Warm & Spicy Indonesian Fusion Sushi Rolls

INDUSHI merges rich Indonesian home-cooked flavors like 12-hour Rendang, Ayam Geprek, Sambal Matah, and Sate Maranggi into 100% cooked, warm, bite-sized fusion sushi rolls wrapped in fragrant Nasi Uduk.

---

## 🚀 Features

- **🔥 100% Cooked & Warm**: No raw seafood—just authentic home-cooked comfort.
- **🍣 Signature Rolls**: Rendang Aburi Supreme, Ayam Geprek Mozza, Sambal Matah Salmon, and more.
- **🛠️ Interactive Custom Sushi Builder**: Mix & match rice bases, proteins, fillings, toppings, and torch levels.
- **🛒 Online Order Cart & Checkout**: Real-time cart calculation with spice level customization.
- **🍱 Platter Towers**: Booking & catering platters for events.
- **⚡ Vite Framework Powered**: Fast development server with Hot Module Replacement (HMR).

---

## 💻 Tech Stack

- **Frontend**: HTML5, Modern Vanilla CSS3, JavaScript (ES Modules)
- **Framework & Build Tool**: [Vite](https://vitejs.dev/)
- **Icons**: FontAwesome 6

---

## 🛠️ Development Setup

### Prerequisites

- Node.js (v18+)

### Installation & Local Server

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AAAACCCCEEEE/INDUSHI.git
   cd INDUSHI
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
